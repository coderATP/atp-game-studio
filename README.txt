ATP GAME STUDIO WEBSITE
========================

This is a static website designed for deployment on HarmonWeb/cPanel.

UPLOAD:
1. Extract this package.
2. Upload all files and folders INSIDE the package into your domain's public_html
   (or the document root assigned to atpgamestudio.com.ng).
3. Keep the assets folder in the same location as index.html.

MAIN PAGES:
- index.html
- about.html
- projects.html
- contact.html
- privacy-policy.html
- terms-and-conditions.html

The ATP Game Studio logo is stored at:
assets/atp-logo.png

The contact form is static and opens the visitor's email client using mailto.
For a server-side form later, replace the form handling with your preferred
HarmonWeb/PHP mail endpoint.

NOTE:
The privacy policy and terms are starter website copy, not legal advice.
Review them for your actual business, analytics, cookies, data collection,
and applicable Nigerian legal requirements before treating them as final.
