How to Set Up and Play a Local Pass-and-Play Quiz on Knovilla

Open Game Mode, select local multiplayer, then choose Pass-and-Play.

Get started

Open Game Mode, select local multiplayer, then choose Pass-and-Play.

Configure or prepare

Set the number of players, difficulty, rounds, subjects, question format, and time per turn. Available subjects include Biology, Chemistry, Physics, and Mathematics.

Continue through the activity

Start the game and allow Knovilla to prepare the selected question pools.

Complete the next step

Follow the pass overlay: hand the device to the named player before continuing. Answer within the configured countdown.

Review and finish

Check the scoreboard and results after the rounds finish. Use the outcome to identify areas for further practice.

Keep exploring

Try these steps in Knovilla or continue to the next guide.
